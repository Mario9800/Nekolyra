================================================================
  Nekolyra  ——  QQ 群 AI 助手
  版本 1.0.4.0
================================================================

这是一个能陪你群里聊天、还有记性的 QQ 机器人。

详细的图文说明在 README.md 里，这个文件只讲**怎么把它跑起来**。


----------------------------------------------------------------
  第一步：跑起来（约 2 分钟）
----------------------------------------------------------------

1. 双击  Nekolyra.exe

   第一次打开会弹一个向导，让你填四个东西：

     管理员 QQ      你自己的 QQ 号（用来管理机器人）
     管理密码       自己设一个，进管理界面要用
     机器人 QQ      你打算拿哪个 QQ 号当机器人
     AI Key         见下面「第二步」

   填完点保存，程序会自己重启。

2. 浏览器会自动打开管理界面。
   如果没自动打开，手动访问：  http://127.0.0.1:8080/admin

   打不开的话看同目录的  startup.log ，里面写了原因。


----------------------------------------------------------------
  第二步：搞一个 AI Key（不想花钱看这里）
----------------------------------------------------------------

机器人要靠 AI 才能说话，有两个选择：

【免费】上海人工智能实验室「墨点计划」
  1. 打开  https://intern-ai.org.cn  微信扫码注册
  2. 在控制台创建一个 API Key
  3. 回到 Nekolyra 的「系统配置」页，这样填：

       后端选择    云端 API（智谱 / DeepSeek / 兼容 OpenAI）
       云端 API 地址   https://discovery-api.intern-ai.org.cn/v1
       云端模型名      deepseek-v4-flash-0731
       云端 API Key    把刚才复制的粘进来

  新用户送的额度够个人用很久。

【免费备选】智谱
  地址   https://open.bigmodel.cn/api/paas/v4
  模型   glm-4.7-flash

【本地跑】装了 Ollama 的话可以完全离线
  后端选择切到「本地 Ollama」，地址 http://localhost:11434
  模型名填你 pull 下来的，比如 qwen2.5:7b
  不花钱，但效果看你的显卡。

填完点「保存」，马上生效，不用重启。


----------------------------------------------------------------
  第三步：让机器人连上 QQ
----------------------------------------------------------------

Nekolyra 自己不能登录 QQ，需要一个"协议端"帮它连。
推荐 NapCat：  https://github.com/NapNeko/NapCatQQ

装好 NapCat、登录你的机器人 QQ 后，把它设成
**反向 WebSocket**，地址填：

    ws://127.0.0.1:8080/onebot/v11/ws

（端口 8080 如果被占用，在 config.json 里改了要同步改这里）

连上之后，「概览」页的日志里会冒出连接成功的提示。


----------------------------------------------------------------
  怎么用
----------------------------------------------------------------

在群里 **@机器人** 然后说话就行，比如：

   @Nekolyra 你好
   @Nekolyra 今天天气怎么样
   @Nekolyra 签到              ← 签到拿积分（需要装了签到插件）
   @Nekolyra 抽奖              ← 抽一个活跃群友（需要装了抽奖插件）
   @Nekolyra 群报              ← 看昨天的发言排行

补充知识（教它新东西）：

   补充知识 问题内容 | 答案内容


----------------------------------------------------------------
  插件：想要什么功能自己装
----------------------------------------------------------------

程序自带 5 个插件，都在「插件」页里管：

   抽奖 · 群报 · 签到积分 · 今日老婆 · 打招呼（示例）

  不要的可以「停用」或「卸载」，想要新的去「插件市场」点安装。
  也能装别人 GitHub 上的插件，把仓库地址贴在「已安装」页底部就行。

  ⚠️ 插件是别人的代码，装在你电脑上能读你的数据。
     只装你信得过的来源。

  ⚠️ 插件的页面不在左边菜单里 —— 在「插件 → 已安装」的卡片上
     点「打开页面」。这样装再多插件，左边菜单也不会乱。


----------------------------------------------------------------
  语音（可选，不开也行）
----------------------------------------------------------------

想要机器人发语音，需要另外跑一个 IndexTTS 服务，
详见 README.md 的「语音怎么开」一节。

不开的话它就只发文字，其它功能一切正常。


----------------------------------------------------------------
  常见问题
----------------------------------------------------------------

Q: 双击没反应 / 闪一下就没了
A: 看 startup.log。最常见的原因是只拷了 Nekolyra.exe，
   没把 _internal 文件夹一起拷过来 —— 两个必须在一起。

Q: 连上了但机器人不回话
A: 1) 「概览」页看 AI 是不是显示已连接
   2) 「系统配置」检查地址和 Key 填对没有
   3) 群里要 @它 才会回

Q: 语音很慢（十几秒甚至三十秒）
A: 打开这个文件：
      %APPDATA%\T8star-Aix · IndexTTS 2.5\settings.json
   把 referenceDevice 改成 "cpu"，能快十倍。

Q: 换台电脑怎么搬过去
A: 整个文件夹拷过去就行，什么都不用重装。
   配置在 config.json，数据在 data\ 里。

Q: 端口 8080 被别的软件占了
A: 用记事本打开 config.json，把 "port" 改成别的（比如 8090），
   重启。管理界面地址也要跟着改端口。

Q: 数据会被传到网上吗
A: 不会。数据库、配置、聊天记录都只在你电脑上。
   唯一的对外通信是你自己配的那个 AI 接口地址。

   但注意：**第三方插件是别人的代码**，不在这个保证范围内。


----------------------------------------------------------------
  想删掉
----------------------------------------------------------------

直接删掉整个文件夹即可，不写注册表、不留后台服务。

想保留数据以后再用，就把 config.json、data\、.env 三个留着。
